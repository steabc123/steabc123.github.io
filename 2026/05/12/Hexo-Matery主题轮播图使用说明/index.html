关键点说明：

  1. 选择器必须是 .carousel-item.bg-cover

    这是最容易踩坑的地方。轮播图的HTML结构是这样的：

    如果只用 .bg-cover:after，浏览器找不到的，因为 .bg-cover 外面还包着一层 .carousel-item。必须写成 .carousel-item.bg-cover:after 才能选中。

  2. 不用重复定义动画

    rainbow 动画已经在主题的 matery.css 里定义好了（第596-686行），我们只需要调用就行，不用再写一遍 @keyframes。

  3. z-index层级很重要

    • 遮罩层（:before 和 :after）的 z-index: 1
    • 内容容器（.container）的 z-index: 2

    这样文字和按钮才能在遮罩上面显示出来，不然就被盖住了。

验证是否成功

改完保存后：

  1. 运行 hexo clean && hexo g && hexo s
  2. 打开 http://localhost:4000
  3. 按 Ctrl + F5 硬刷新（这一步很关键！）
  4. 应该能看到banner上有紫色到粉色的渐变遮罩，并且会慢慢变色

如果还是看不到：

  • 按 F12 打开开发者工具
  • 切换到 Elements 标签
  • 找到 <div class="carousel-item bg-cover"> 这个元素
  • 看它的 :after 伪元素有没有应用 animation: rainbow 60s infinite
  • 检查有没有其他CSS规则把它覆盖了（比如 display: none）

其他常见问题

Edge浏览器不显示遮罩

现象： Firefox正常，Edge和Chrome看不到彩虹渐变。

原因： 浏览器缓存了旧的CSS文件。

解决： 硬刷新就行。

  • Windows: Ctrl + F5
  • Mac: Cmd + Shift + R

我之前以为是兼容性问题，加了一堆 -moz-、-o- 前缀，结果发现根本没必要。现代浏览器都支持标准CSS动画，清除缓存就好了。

教训： 遇到显示问题先清缓存，别急着改代码。

总结

折腾这一圈下来，有几个心得：

  1. 改之前先备份：特别是模板文件，改错了很难找回
  2. 善用开发者工具：F12看DOM结构和CSS应用情况，比瞎猜快多了
  3. 缓存是大坑：CSS改了不生效，90%是缓存问题，先硬刷新试试
  4. 保持代码简洁：不要为了兼容性加一堆没用的前缀，现在浏览器都很标准了

轮播图本身不难配置，难的是理解它的DOM结构和CSS选择器的关系。搞清楚这一点，想怎么改就怎么改。
